# Targeted 27-spin level-crossing analysis

Start with **crossing_report.md**, **crossing_brackets.csv**, **ground_samples.csv**, and **cell_sector_comparison.csv**. All calculations are static ground/competing-level ED; no dynamical spectrum is invoked.

The model is unchanged: J=1, 3x3 three-site cells, N=27, fixed N_up=14 (Sz=+1/2). The full population basis contains 20,058,300 states. Ground searches include every half-integer S multiplet because each has an M=+1/2 component. Cell momentum is n/3. A checkpoint's `q` is a convenient physical-coordinate character argument; at unequal couplings it is not an independently conserved primitive momentum. Fold it as k=(q1+q2,2q1−q2) modulo integers.

## Reproduce cached tables/figures

Requirements: Python 3.12, NumPy, SciPy, Matplotlib, and g++ with OpenMP for any operator recomputation. Exact versions and hardware appear in requirements.txt and environment.json.

```sh
OPENBLAS_NUM_THREADS=1 python run_analysis.py
```

## Recompute eigenpairs and refinement

```sh
OPENBLAS_NUM_THREADS=1 python run_analysis.py --tests --compute
```

This can require substantial CPU time: inspect computational_cost.json for measured work under a two-CPU quota. The calculation reuses verified eigenpair files and available checkpoints. No full 27-site Hamiltonian matrix is assembled. Matrix construction appears only in small validation tests.

The initial scans calculate 0.275, 0.35, 0.425. Every explicitly solved minimum uses a cold generic pseudorandom start (seed 2026), not a pure-spin endpoint continuation. Adaptive bisection classifies new global ground states, aiming at bracket width below 0.005. Higher spatial characters may instead be excluded by eigenvalue-concavity lower bounds; such bounds are explicitly labeled and are never presented as computed eigenvalues.

The three inequivalent cell momentum stars have sizes 1,6,2. Compatible C6, C2 and C3 little-group characters further reduce the work. Gamma characters 4/5 are conjugate to 2/1. At the corner star C3 characters 1 and 2 have exactly equal spectra by a verified reflection. Quantum-number labels record S, cell n, cyclic character and compatible reflection parity. `character` means a C6 angle index at Gamma, a reflection sign index at the six-momentum representative, and a C3 angle index at the corner representative.

All actual eigenvectors pass fresh original-H residual and total-S-squared checks. Physical-vector deflation obtains additional levels without counting the artificial doubled-real representation as physical degeneracy. Its shift is larger than the full Hamiltonian spectral-width bound. `test_crossing.py` and `test_complex_deflation.py` independently verify this on small projected Hamiltonians, including complex sectors.

## Static observables and limits

`postprocess.py` evaluates representative ground states and explicitly labeled competing states at common couplings near the crossings. Scalar observables are SU(2)-multiplet and exact point-group averages. m_N^2=C_nn(Gamma)/36 and S_h(k)=C_HH(k), with all spin components included. The selected fixed-M mean is not mistaken for a symmetry-averaged magnetization.

`ladder_*.json` supplies an independent static spin-multiplet check of the new S=7/2 state: raising norms 15,12,7,0 and equal-energy partners. Those auxiliary M sectors are for spin verification only. Ground-state scans always remain at M=+1/2.

The data resolve observed finite-cluster crossings, not thermodynamic transitions. Signed competing-level differences are not a complete excitation gap. Continuous spatial-family exclusions and any remaining ambiguous intervals are saved explicitly. Same-family spin islands finer than the audit spacing are not rigorously excluded. Plotted connecting lines guide the eye between verified samples; they are not additional eigensolver results.

Stage 3 remains unstarted. Selection rules and three proposed dynamical coupling values are recommendations only; no response function, spectral weight or linewidth is computed.
