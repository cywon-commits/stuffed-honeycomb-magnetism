# Targeted Stage 3 dynamics

Read report.md and CONVENTIONS.md. Cached tables, unbroadened pole residues, exact moment matrices, and explicitly approximate Krylov quadrature are separate products.

Run `OPENBLAS_NUM_THREADS=1 python dynamics/run_dynamics.py` from the archive root for cached reporting. Add `--tests` for the independent small-cluster operator/moment test. Add `--compute` for expensive ED, followed by spectral quadrature. Python, NumPy, SciPy, Matplotlib and g++/OpenMP versions are recorded. All physical eigenpairs require direct residuals; quadrature nodes are not asserted converged eigenvalues.

The sibling crossing/ directory contains the seven input verified checkpoints and metadata needed by the scripts. All ground searches stay in Nup=14. New target vectors are regenerated by the solver; not all intermediate vectors are distributed. kernel.cpp is compiled locally on demand. weak_seeds.npz is regenerated by weak_spectrum.py --moments-only and is deliberately omitted from the archive because of its size.

The low-pole solve is partial; exact seed moments include uncomputed high-energy states. The block quadrature reconstructs moment-complete approximate spectra and labels every node approximate. No broadened curve is presented as a physical linewidth. Summed spectral moments of a truncated verified-pole list are not expected to saturate the exact moments; remainders are saved explicitly.
