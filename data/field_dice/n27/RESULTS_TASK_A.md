## 4. 계산 방법과 검증

- 해법: `src/ed36/ed_sym` (대칭화된 행렬 없는 Lanczos, C++/OpenMP)에 세 결합을 넣었다. 결합 종류는 0 = A–B (J_AB), 1 = hub–B (J_BC), 2 = hub–A (J_CA)다. 거울선 위에서는 셀 평행이동 9개와, hub를 고정하는 점군 연산을 함께 썼다. 결합 값이 같은 결합끼리만 서로 바뀌도록 그래프 자기동형사상을 계산해서 대칭군을 정한다.
- 운동량: Sᶻ = 1/2, 3/2는 r = 0.4에서 9개 운동량을 모두 계산했다. 그 결과 최저 준위가 Γ에 있음을 확인한 뒤, r = 0.6과 0.8에서는 Γ, K, K′로 제한했다(명세 허용). 나머지 Sᶻ는 9개 운동량을 모두 계산했다. H가 실수이므로 k와 −k의 스펙트럼은 같다. 따라서 −k 행은 k에서 복사했고 `source` 열에 그렇게 표시했다.
- 품질: 159행 모두 수렴했다. ‖Hψ − Eψ‖ ≤ 1.0e-9이고, ‖S²ψ − S(S+1)ψ‖ ≤ 1.04e-8이다. S는 S² 작용에서 얻었다.
- 단위 테스트 U1–U6 모두 통과(`unit_tests.json`):
  - U1: `geometry()`와 결합 81개가 하나씩 모두 일치한다.
  - U2: 검증된 27스핀 바닥 에너지와 S를 재현한다(|ΔE| ≤ 5e-13).
  - U3: 대칭 축소 없는 독립 계산값 40개와 일치한다(max |ΔE| = 4.5e-13).
  - U4: 포화 자기장 공식과 정확히 일치한다.
  - U5: Lieb–Mattis 변에서 S = 9/2다.
  - U6: 에르미트성 오차 5e-14이고, 12사이트 세 결합 전체 스펙트럼이 3.7e-14 이내로 일치한다.
