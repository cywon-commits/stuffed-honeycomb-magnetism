## 계산 품질과 방법

- 모든 행이 수렴했다. Task B는 ‖Hψ − Eψ‖ ≤ 9.9e-10, ‖S²ψ − S(S+1)ψ‖ ≤ 2.5e-9이다. Task D는 각각 ≤ 9.1e-10, ≤ 1.9e-9이다.
- 해법은 Task A와 같다(`src/ed36/ed_sym`, 결합 값 라벨 그래프의 자기동형사상으로 대칭군 결정). 거울선 밖 점에서는 셀 평행이동 9개와 hub 중심 C3 회전을 쓴다. C3 회전은 세 부분격자를 각각 보존하므로 어떤 결합에서도 대칭이다.
- H가 실수이므로 k와 −k의 스펙트럼은 같다. −k 행은 k에서 복사했고 `source` 열에 표시했다.
- 단위 테스트 U1–U6 모두 통과(`unit_tests.json`, 내용은 `RESULTS_TASK_A.md` 4절).

## 주의점

- Task B의 h_lo는 명세대로 Sᶻ = 7/2와 9/2 두 섹터만으로 정했다. 완전한 Maxwell 구성 h_lo = max_{m<9/2}(…)에 더 낮은 Sᶻ를 넣으면 h_lo는 **커질 수는 있어도 작아질 수는 없다**. 그래서 여기 값은 하한이다. Task A의 거울선 점들에서는 7/2 항이 최대였으므로 차이가 없었지만, 이 결합점들에서 같은 성질이 성립하는지는 Sᶻ ≤ 5/2를 계산하지 않아 확인하지 못했다. h_hi와 h_hi/h₊는 이 문제와 관계없다.
- 크기는 18과 27 두 개뿐이다. 배율 1.51 → 1.44와 f 0.82 → 0.86의 경향을 열역학 극한값으로 외삽하지 않는다.
