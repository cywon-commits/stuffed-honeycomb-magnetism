# 27스핀 3차 계산 의뢰서 (Task H: 쐐기 축척 판별)

작성 2026-11-19 · 1차(`27SPIN_THREE_COUPLING_REQUEST_EN.md`, Task A–D)와 2차(`27SPIN_2차_의뢰서_E-G_KO.md`, Task E–G)의 후속이다.
코드, 캐시, 단위 테스트, 출력 규약은 1·2차와 같고, 같은 브랜치(`claude/stoic-ptolemy-l3eac5`)에 이어서 커밋한다.

## 0. 왜 이 계산이 필요한가

Task C는 육각형 거울선 근처 J = (1, j + d/2, j − d/2)에서, 바닥 스핀이 처음 1/2 → 3/2로 뛰는 문턱 d_c를 두 j에서 주었다(`summary_n27.csv`, C행).

| j | d_c 구간 | d_c/j | d_c/j² |
| --- | --- | --- | --- |
| 0.15 | (0.00750, 0.00875] | 0.050–0.058 | 0.333–0.389 |
| 0.20 | (0.01125, 0.01250] | 0.056–0.063 | 0.281–0.313 |

원고 초안은 "쐐기 폭 ∝ j²"라고 썼다. 독립 검토 결과, 이 두 점은 오히려 j에 대한 **선형** 축척을 지지한다.
- 비 d_c(0.2)/d_c(0.15)는 1.29–1.67이다. 선형이면 1.33으로 이 범위 안에 들고, 이차면 1.78로 범위 밖이다.
- d_c/j²의 두 구간은 서로 겹치지 않는다.

두 축척은 j가 작을수록 크게 갈린다. 이번 의뢰의 목적은 작은 j 두 점을 추가해 축척을 판별하는 것이다.

이와 별도로, 18스핀과 27스핀은 서로 다른 전이를 비교했다는 지적도 있었다.
- 18스핀 K18은 S = 0 → 3으로 바로 페리자성이 되고, C18은 0 → 1이다.
- 27스핀은 1/2 → 3/2다.
- 이론 예측(허브 포화 기준)은 "완전 편극" 쪽에 대응한다.

그래서 이번에는 첫 점프에 더해, S가 페리자성 값 N/6 = 9/2에 이르는 문턱도 기록한다.

## 2. Task H1 — 작은 j의 첫 점프 문턱 (우선순위 1)

**점.** J = (1, j + d/2, j − d/2), j ∈ {0.10, 0.125}. 시간이 남으면 j = 0.175도 계산한다(0.15와 0.2 사이 점검용).

**절차.** Task C와 같다. 각 d에서 Sᶻ = 1/2, 3/2(필요하면 5/2)의 최저 준위를 운동량 9개 모두에서 구하고, S²로 바닥 S를 정한 뒤, d에 대해 이분법을 쓴다. 다음을 먼저 확인한다.
- d = 0에서 바닥 S가 1/2인지. 아니면 Task C의 j = 0.3처럼 판정 불가로 기록하고, 해당 j는 건너뛴다.
- 이분법 해상도는 아래 표 마지막 열의 값보다 작아야 한다.

**판정용 예측.** 선형 계수는 27스핀 두 점의 공통 구간 0.056–0.058을, 이차 계수는 0.28–0.39를 쓴다.

| j | 선형 예측 d_c | 이차 예측 d_c | 필요한 이분법 해상도 |
| --- | --- | --- | --- |
| 0.100 | 0.0056–0.0058 | 0.0028–0.0039 | ≤ 0.0004 |
| 0.125 | 0.0070–0.0073 | 0.0044–0.0061 | ≤ 0.0004 |
| 0.175 | 0.0098–0.0102 | 0.0086–0.0119 | ≤ 0.0004 (판별력 약함, 점검용) |

**판정 규칙.**
- j = 0.1과 0.125의 d_c가 둘 다 선형 예측 구간과 겹치고 이차 예측과는 겹치지 않으면, 27스핀 문턱은 j에 선형이다.
- 반대면 이차다.
- 둘 다 아니면, 네 j 값에 d_c = a·j^p를 최소제곱으로 맞춘 p와 그 범위를 보고한다.

## 3. Task H2 — 페리자성 문턱 (우선순위 2)

**점.** j ∈ {0.10, 0.15, 0.20}이다. 0.15와 0.2는 Task C 캐시를 최대한 재사용한다.

**절차.** 첫 점프 뒤로 d를 늘리며 바닥 S를 추적한다. 격자는 d = d_c부터 Δd = 0.0025 간격으로, S = 9/2에 이르거나 d = 2j²에 이를 때까지 계산한다. 각 단계에서 바닥 S가 바뀌는 구간을 이분법으로 Δd ≤ 0.0005까지 좁힌다.
- 섹터: Sᶻ = 1/2 … 9/2의 최저 준위. 바닥 S가 Sᶻ로 정해지는 섹터만 계산해도 된다.

**출력.** `task_H.csv`(원자료)를 만든다. `summary_n27.csv`에는 H행으로 다음을 넣는다.
- j마다 S 계단의 각 문턱: d(1/2→3/2), d(3/2→5/2), …, d(→9/2)
- d_full = d(S = 9/2)

비교 기준은 이론 예측 0.34–0.37 j²다. 이 값은 허브 포화 기준이므로 d_full과 비교하는 것이 맞다. 고전 쐐기 j²도 함께 적는다.

**비용 예상.** Task C(약 10.2시간, j 세 개)를 기준으로 H1은 약 7시간이다. H2는 Sᶻ가 큰 섹터가 작아서 상대적으로 가볍다.
