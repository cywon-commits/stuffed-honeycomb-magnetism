# 36스핀 계산 의뢰서 (Task I: 거울선 플래토의 세 번째 크기)

작성 2026-11-20. 27스핀 1–3차 의뢰(Task A–H)의 후속이다. 풀이기는 저장소의 `src/ed36/`(대칭 축소 행렬 없는 Lanczos, `ed_sym.cpp` + `symmetry.py`)를 쓴다.
- 이 풀이기의 모형은 거울선 모형 J_AB = J = 1, J_BC = J_CA = J′ = r과 같다.
- 36사이트 원환은 T = [[2,2],[−2,4]]다.
- 결과는 원고 완성 후 반영할 예정이므로 급하지 않다.

## 0. 왜 이 계산이 필요한가

원고는 육각형 거울선(r < 1)의 1/3 플래토를 다음과 같이 설명한다.
- 고전적으로는 "허브 ↑ + 림 Néel 벡터의 방향은 자유"다.
- 스핀파 영점 에너지가 공선 상태를 고른다. 선택 에너지는 K = S·k(r)이다.
- 그 결과 폭이 √S에 비례하고 1차 spin-flop으로 끝나는 플래토가 생긴다.
- 유한 클러스터에서는 림이 회전자 H = L²/2I − D·n_z²로 행동한다. 이론값은 I = N/(9J), D = N·K다.

지금 근거는 18사이트와 27사이트 두 크기뿐이다.
- 27사이트에서 r = 0.8, 0.9의 Sᶻ 계단을 맞추면 I = (1.07–1.08)N/9, D/N = (1.04–1.09)K다(`data/field_dice/rotor_fit_ladder.csv`).
- 림 이방성 Δ는 18 → 27에서 2.0–2.9배 커졌다.

"크기와 함께 커진다"는 관찰은 두 점만으로는 포화(벌크 선택)와 다른 축척을 구별하지 못한다. 36사이트에서 x = DI ≈ 2.5(r = 0.8)가 되면, 선택이 있을 때와 없을 때의 예측이 크게 갈린다(3절 표). 이번 의뢰의 목적은 이 세 번째 크기다.

## 1. 공통 규약

- 결합: 거울선 J = (1, r, r), S = 1/2. N = 36이므로 N/6 = 6(플래토 섹터 Sᶻ = 6)이다.
- 섹터: 운동량 k와 작은 군의 1차원 표현. 풀이기의 기본 동작대로, Γ에서는 C6, K에서는 C3의 순환 부분군을 쓴다. "섹터 최저 준위"는 계산한 모든 (k, 표현)의 최소다.
- 수렴: ‖Hψ − Eψ‖ ≤ 1e-8. 최저 준위는 섹터 안에서 다음 준위와 1e-6 이상 떨어져야 하고, 그렇지 않으면 축퇴로 보고한다.
- 출력: `data/field_dice/n36/` 아래에 원자료 `task_I.csv`를 둔다. 열은 r, Sz, k, irrep, dim, E, residual, iterations, 그리고 관측량이 있으면 그 열이다. 요약은 `summary_n36.csv`, 문서는 `RESULTS_TASK_I.md`로 한다.
- 실행 기록(`RUN_LOG.md`): 환경, 코어 수, 섹터별 시간과 메모리를 적는다.

## 3. Task I1 — r = 0.8의 Sᶻ 계단 (우선순위 1)

**상태.** Sᶻ = 5, 6, 7, 8 각각의 최저 준위를 구한다(플래토 섹터 6과 m = −1, +1, +2).
- Γ: 모든 1차원 표현.
- K: 모든 1차원 표현.
- 27사이트에서는 플래토 근처 섹터의 최저가 모두 Γ였다. 36사이트에서 Γ가 아니면 다른 운동량도 계산하고 보고한다.
- Sᶻ = 4(m = −2)는 선택 사항이다. 넣으면 대칭 조합으로 맞출 수 있다. 빼면 (m = −1, +1, +2)와 미지의 플래토 중심 이동 h₀로 맞춘다(아래 판정 참조).

**관측량.** Sᶻ = 5, 6, 7의 최저 상태에서 파쌍 궤도 합(`--pairs`)으로 다음을 구한다.
- zz_AB = ⟨Σ_{A–B} S^z S^z⟩/N_AB, t_AB = ⟨Σ_{A–B}(S^xS^x + S^yS^y)⟩/N_AB. 여기서 N_AB = 36이다.
- 같은 방식으로 허브 결합의 zz, t를 구한다.
- 축퇴 다중항이면 평균을 낸다.

**판정량.**
- W₃₆ = (E₇ − E₆) + (E₅ − E₆): 세 섹터로 Maxwell 구성. 다른 Sᶻ가 경계를 정하는지 확인하려면 Sᶻ = 4, 8을 함께 쓴다.
- Δ₁ = (E₇ + E₅)/2 − E₆, Δ₂ = (E₈ + E₄)/2 − E₆(Sᶻ = 4를 넣었을 때). Sᶻ = 4가 없으면 E_m − E₆ = e_m(x)/I − h₀·m (m = −1, 1, 2)를 풀어 x, I, h₀를 정한다.
- 림 이방성 Δ = zz_AB/t_AB − 1/2(Sᶻ = 6).

**예측(회전자 이론).** 보조 값은 x = DI, q = ⟨n_z²⟩다.

| 양 | 선택 없음 (D = 0) | LSWT (I = N/9, D = N·K) | 27사이트 맞춤값 (I = 1.075N/9, D/N = 0.0179) | 27사이트 실측 |
| --- | --- | --- | --- | --- |
| x₃₆ | 0 | 2.48 | 2.77 | (x₂₇ = 1.40–1.56) |
| W₃₆ | 0.500 | 0.735 | 0.718 | W₂₇ = 0.782 |
| Δ₂/Δ₁ | 3.00 | 2.48 | 2.43 | 27: 2.67 |
| (q − 1/3)₃₆/(q − 1/3)₂₇ | — | 1.83 | 1.82 | Δ₂₇ = 0.329 |

**판정 규칙.**
- W₃₆이 0.70–0.77이고 Δ₂/Δ₁가 2.3–2.6이면, 회전자 + LSWT 선택이 세 번째 크기에서도 성립한다(원고 P7‴ 지지).
- W₃₆ ≈ 0.50(±0.05)이고 Δ₂/Δ₁ ≈ 3이면, 선택은 크기와 함께 사라진다.
- 그 밖이면 맞춘 x, I, D/N를 보고한다.
- 주의: 이방성 Δ의 36/27 비는 예측이 1.8로 N² 비 1.78과 거의 같다. 따라서 Δ만으로는 포화(곡률)를 판별할 수 없다. W₃₆과 Δ₂/Δ₁가 결정적인 양이다.

**비용 예상.** 대칭 축소 후 섹터 차원은 Sᶻ = 8 약 180만, 7 약 420만, 6 약 870만, 5 약 1600만, 4 약 2600만이다. 2026-11 벤치마크(3150만 차원에서 H 작용 약 66초, 4코어)로 비례 추산하면 Lanczos 약 200회는 섹터당 Sᶻ = 8 약 0.2시간, 7 약 0.5시간, 6 약 1시간, 5 약 2시간, 4 약 3.5시간이다. Γ와 K의 표현을 모두 계산하면 r 하나당 1–2일이다. Sᶻ = 6을 먼저 계산해 최저 표현을 확인하고, 나머지는 그 결과를 보고 순서를 정해도 된다.

## 6. Task I4 — 페리자성 문턱의 세 번째 크기 (선택, 비용 큼)

**목적.** 거울선 근처 J = (1, j + d/2, j − d/2)에서, 바닥 스핀이 페리자성 값 S = N/6 = 6에 이르는 문턱 d_full의 계수가 크기와 함께 유한한 값으로 수렴하는지, 0으로 가는지를 본다.
- 계수는 18(K18) 0.209j, 27사이트 0.164j였다.
- 1/N_H에 선형으로 수렴한다면 36사이트 계수는 약 0.142다(벌크 0.074). 이때 j = 0.15에서 d_full ≈ 0.0212다.
- 계수가 1/N_H로 0에 간다면 0.123이고, d_full ≈ 0.0185다.

**절차.** j = 0.15 하나만 계산한다.
- 이 경우 J_BC ≠ J_CA이므로 `Cluster(name, couplings=(1, J_BC, J_CA))`로 대칭군을 다시 구한다. 군의 크기가 줄어든다.
- 각 d에서 Sᶻ = 0 … 6의 최저 준위로 바닥 S를 정하고, d ∈ [0.012, 0.030]에서 이분법(해상도 ≤ 0.0005)으로 S = 6이 되는 문턱을 찾는다.

**비용.** Sᶻ = 0 섹터는 축소된 대칭군에서 수억 차원일 수 있어 매우 비싸다. 먼저 `--mode dim`으로 차원을 보고하고, 실행 가능하다고 판단될 때만 진행한다.
