# 27스핀 계산 의뢰서 (세 결합 삼각 격자, 요약)

작성일: 2026-11-18. 실행 명세 원문은 `27SPIN_THREE_COUPLING_REQUEST_EN.md`이고, 이 문서는 한국어 요약이다.
연구계획: https://claude.ai/artifact/EoRrJbnJmc8erKYMbU6eGj

## 무엇을 바꾸나

검증된 27스핀 코드(`src/history/hub_ground_state_crossings_verified/hub_ground_state_crossings/ed.py`)는
결합마다 계수 배열을 받는다. 허브 결합을 C–A(J_CA)와 C–B(J_BC)로 나누는 `geometry3`만 더하면 된다.
C++ 커널은 그대로 쓴다. φ가 거울선이 아니면 셀 평행이동만 쓴다.

## 단위 테스트 (먼저 통과)

- 기존 27스핀 검증값 재현: J = (1, r, r), Sᶻ = 1/2에서 r = 0.275, 0.35, 0.425의 바닥 에너지
- 대칭 축소 없는 독립 계산값과 일치: `data/field_dice/reference_N27_highSz.csv` (Sᶻ ≥ 13/2, 다섯 결합점)
- 포화 자기장 = 9SJ̄(1+ε), Lieb–Mattis 변(J_CA = 0)에서 S = 9/2

## 계산 네 가지와 판정 기준

| 작업 | 결합점 | 섹터 | 판정 |
| --- | --- | --- | --- |
| A. r < 1 벌크 플래토 | J = (1, r, r), r = 0.4, 0.6, 0.8 | Sᶻ = 1/2–13/2 | W₂₇이 (1/χ − 3r)/9 띠(0.42–0.67)보다 크면 벌크 플래토 |
| B. 위 경계 배율 | (ε, φ) = (0.1, 30°), (0.2, 30°), 다이스, (0.1, 60°) | Sᶻ = 7/2, 9/2, 11/2 | 18스핀 배율 1.51이 방향과 무관하게 유지되는지 |
| C. 부분무질서 쐐기 | J = (1, j + d/2, j − d/2), j = 0.15, 0.2, 0.3 | Sᶻ = 1/2–9/2 | δ_c ≈ 0.14j(유한크기) 대 0.34–0.37j²(벌크) |
| D. 공명 효율 | 다이스, (0.56, 30°), 육각형 J = (1, 0, 0) | Sᶻ = 9/2 | f₂₇이 18스핀 0.82에서 LSWT 0.89 쪽으로 가는지 |

순서는 A, B, D를 먼저 하고 C를 마지막에 한다. 시간이 부족하면 C는 j = 0.15, 0.2를 우선한다
(유한크기 0.021, 0.028 대 벌크 0.0076, 0.0135). j = 0.3은 두 예측이 가까워 확인용이다.

정정 (2026-11-18): 처음 판에 적은 벌크 예측 0.13j²는 쌍 규약을 잘못 맞추고 횡방향 결합을 빠뜨린 값이었다.
