This is a **self-contained research handoff**, not a claim that a completed low-Sz 36-spin eigensolver exists. All archived code and the available checkpoints from this ChatGPT project are packed with byte-for-byte original archives, plus the latest finite-size workspace expanded for immediate use.

## Fast start: runnable latest workspace

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cd workspaces/finite_size_18_27_36pilot
find . -name '*.so' -delete # always rebuild native C++ for the target CPU
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 python run_all.py --tests
```

The default run reuses precomputed converged checkpoints; `--compute` requests expensive computations. For a strict cold rerun, read the workspace README first and preserve reference27 inputs. C++ toolchain: `g++` with OpenMP. This package does not automatically submit HPC jobs or install an HPC-specific solver.

## Directory layout

- `workspaces/finite_size_18_27_36pilot/`: extracted latest full 18/27/36-pilot archive including all checkpoints and source.
- `source_code_all_stages/`: code, C++, markdown, tables, configurations from **all original archives** under per-archive names. This duplicates small files by design so nothing is hidden inside ZIP.
- `original_archives/` (**FULL package only**): original complete ZIPs, including all available stage 1/2/3, 27-spin, crossing, weak-coupling pole checkpoints, ABC triangle, and finite-size work. For archival reproducibility; individual archives may contain duplicate data.
- `standalone_reference/`: other project files and prior task specs.
- `guides/`: execution request in English and Korean.
- `scripts/`: verification/smoke and optional scheduler template.
- `manifests/`: original archive SHA256 and sizes.

## Resource warning
N=36 with Sz=0 has C(36,18)=9,075,135,300 raw states. One Gamma translation sector contains 756,273,594 vectors, needing 11.27 GiB per complex128 vector and 42.26 GiB for the existing dense combinatorial lookup scheme. The supplied 36-spin code contains only high-Sz benchmarks, NOT a low-Sz 36-spin converged ground state. A new memory-lean solver may be needed. Before requesting expensive hours, benchmark actual reduced sectors and report peak resident memory and H-action timings.

## Integrity
Run `python scripts/verify_archive_checksums.py` in the root of the FULL extracted package. In the CORE package, the original archive manifest is supplied for provenance but original zip files are deliberately omitted; use `--workspace-only` to inspect the expanded working directory.

## Limitations
No new ED results have been generated by repackaging. Results reported by previous Codex runs are archived, not independently re-computed during package construction. Original zipped files preserve their historical code and results, including distinct conventions documented in each readme; do not mix per-stage Fourier normalizations without validation.
